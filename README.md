## 시장 상황 메모 (2026-10)

- **GPU**: 수급 부족으로 가격 상승. RTX 5090은 400만원대+ 로 사실상 구매 비추. RTX 5080이 현재 고사양 게이밍의 실용적 상한.
- **NAND/SSD**: 2TB 제품이 57~90만원대로 전년 대비 상승. 해외구매가 국내보다 유리.
- **RAM**: DDR5 32GB 키트가 69~90만원. CL30/CL36 vs CL38 체감 차이는 게이밍에서 제한적.
- **CPU**: 9800X3D가 게이밍 왕좌. 예산이 빠듯하면 7800X3D가 가성비 우수.
